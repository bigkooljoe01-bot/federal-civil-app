68. Who is responsible for receiving allegations that a public officer has committed a breach of

the Code of Conduct?

A. The Head of the Civil Service of the Federation.

B. The Federal Civil Service Commission.

C. The Code of Conduct Bureau.

D. The President.

Correct Answer: C.

Explanation: Any allegation that a public officer has committed a breach of or has not complied

with the provisions of this Code shall be made to the Code of Conduct Bureau.

69. A public officer who does an act prohibited by the Code through a nominee, trustee, or other

agent is deemed to have done what?

A. Nothing, as they did not do it personally.

B. To have committed a breach of this Code.

C. To have acted lawfully.

D. To have fulfilled their duty.

Correct Answer: B.

Explanation: A public officer who does any act prohibited by this Code through a nominee,

trustee, or other agent shall be deemed ipso facto to have committed a breach of this Code
