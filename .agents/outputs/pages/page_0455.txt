39. What is the purpose of a "handing-over note"?
A. To record the personal assets of an officer.
B. To detail the projects, files, and responsibilities of a position for a successor.
C. To document all the money spent by an officer.
D. To explain why an officer is leaving the Service.
Correct Answer: B.
Explanation: The handing-over note is a detailed document that summarizes all the projects,
files, and responsibilities that an officer is handing over to their successor.
40. What should be done with all files in an office at the close of work each day?
A. They should be left on the desk for the next day.
B. They should be locked up in a cabinet.
C. They should be taken home by the officer.
D. They should be given to a junior officer to keep.
Correct Answer B.
Explanation: All files and documents must be locked up in a cabinet at the close of work each
day.
41. The process of creating a new file should be guided by what?
A. The number of documents.
B. The needs of the officer.
C. The existing File Index.
D. The opinion of the Head of Department.
Correct Answer: C.
Explanation: New files should be created based on the existing File Index to ensure the
consistency and logic of the file numbering system.
42. What is the purpose of the “File Index"?
A. To list all the staff in a Ministry.
B. To provide a list of all the files in a Ministry and their unique reference numbers.
C. To track the salary of each officer.
D. To record all the meetings held in a Ministry.
Correct Answer: B.
Explanation: The File Index is a list of all the files in a Ministry, with their corresponding unique
reference numbers.
